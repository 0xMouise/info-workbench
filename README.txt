================================
信息收集工作台 - 使用说明
================================

推荐入口
--------
双击：启动-v9本地工作台.cmd

停止服务
--------
双击：停止-v9本地工作台.cmd

当前版本
--------
info-workbench-v9/ - 前后端分离本地工作台

- HTML / CSS / JavaScript 独立前端
- Node.js 本地 API 与 WebSocket
- SQLite 权威数据源
- Agent/MCP 可在页面关闭时直接写入数据库
- MCP 不包含、不启动任何扫描器
- 数据库：info-workbench-v9\data\workbench.db
- 详细文档：info-workbench-v9\README.md

注意
----
修改 Codex MCP 配置或升级 MCP 代码后，需要重新启动 Codex。
